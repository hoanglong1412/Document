# Git turtotial

## 1. Rebase
Using Git extensions
- Step 1: Choose `Select commit interactively…`	
- Step 2: Edit what you want (order-by, fixup, pick, drop,…)	
- Step 3: Save and close dialog	 (Delete all data of dialog and save to abort rebase)
